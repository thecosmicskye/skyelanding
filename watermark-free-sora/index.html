Watermark-Free Sora

Install the helper once. Capture the Android session once. Keep the web player easy.

The Chrome extension uses a real Android Sora session. The helper app sets up the emulator flow, launches sign-in, captures the token, and hands it back to the extension.

Download the helper

Pick your platform and run the helper. It downloads the preserved runtime patch pack and the Android base pieces automatically, then you come back to the extension and use Import Captured Token.

Download for Windows Download for macOS

The Chrome extension itself stays separate. If you already have a valid Android token, you can paste it directly into the extension instead of running the helper.

Need a helper license first? Grab it in Discord, then paste it into the helper when it asks.

What happens

1. Install the helper It registers the local native bridge, downloads the preserved patch pack, and prepares the Android runtime.
2. Sign in once Finish login in the Android emulator, including Google auth and any second factor.
3. Import the token The extension reads the captured session from ~/.config/sora-spoof/token.json.
